(ne pas confondre avec « [Role Mag'](../role-mag/) », magazine paru dans les années 90).<br>Jusqu'en 2014, JdR mag' fonctionne sur le mode des sites participatifs : les contributeurs peuvent suggérer sur internet le futur contenu du magazine.<br>JdR mag' a été repris en 2014 (soit à partir du [numéro 28](http://fanzines.jdr.wiki.free.fr/wiki/index.php?title=Jeu_de_Rôle_Magazine#Num.C3.A9ro_28)) par le [Département des Sombres Projets](http://www.legrog.org/editeurs/departement-des-sombres-projets).<br>JdR mag'  a sa [Fiche Wikipédia](https://fr.wikipedia.org/wiki/Jeu_de_Rôle_magazine). |  |  |

Pour les numéros antérieurs, [Federico](http://www.black-book-editions.fr/forums.php?topic_id=12094&nbp=3&nop=2) nous annonce : « Pour les numéros antérieurs au 28, la personne de Titam qui m'a gentiment et rapidement répondu ne désespère pas… » | **Adresse physique :** 95, rue Sedaine - 75011 Paris |
| **Fondateur / Responsable :** Jusqu'en 2014, le magazine est géré par un regroupement de rôlistes bénévoles, l'association « Promenons-Nous dans les Bois » dont le président est Guillaume Besançon. Il paraît en kiosque. Actuellement, Jean-Luc Boukhari. | **Éditeur :** Association Promenons-Nous dans les Bois.
