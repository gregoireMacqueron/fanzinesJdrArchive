#### À quoi correspondent les rubriques de la Fiche de Fanzine
- **Titre :** titre du fanzine (généralités)
- **Couverture :** image d'une des couvertures (si possible le n°1 ou n°0)

- **Code ISSN :** code issn
- **Langue :** la langue
- **Thème / Jeu :** le thème abordé / le(s) jeu(x) spécifiquement traité(s)

- **Description :** description

- **Remarque :** remarque

- **Format :** papier / numérique • A4 / A5 • À l'italienne
- **Impression :** offset / sérigraphie / photocopie / autre / PoD / numérique uniquement (pour un pdf)
- **Adresse physique :** adresse physique (ou siège) du fanzine

- **Fondateur / Responsable :** le nom du/des fondateur(s) / responsable(s)
- **Éditeur :** le nom de l'éditeur
- **Rédac’chef :** le nom du/des rédac’chef

- **Site web :** site web hébergeant (ou dédié) au fanzine
***Prix :** prix au numéro (peut évoluer avec le temps)
- **Nombre total de n° :** nombre total de n° parus

- **Périodicité :** hebdomadaire / bimensuel / mensuel / bimestriel / trimestriel / semestriel / variable / autre
- **Début parution :** date de début de parution
- **Fin parution :** date de fin de parution / en cours
