***généraliste**

*Ce qui donnera :* **Thème / Jeu(x) :** généraliste

***un jeu en particulier :** faites pointer le jeu en question vers la base de données du Guide du Rôliste Galactique (GROG) http://www.legrog.org

*Exemple pour L'Appel de Cthulhu :*
<NOWIKI>
[L'Appel de Cthulhu](http://www.legrog.org/jeux/appel-de-cthulhu)
</NOWIKI>

*Ce qui donnera :* **Thème / Jeu(x) :** [L'Appel de Cthulhu](http://www.legrog.org/jeux/appel-de-cthulhu)

***un système de jeu en particulier :** faites pointer le(s) jeu(x) en question vers la base de données du GROG http://www.legrog.org

*Exemple pour Le BRP :*
<NOWIKI>
[Les jeux motorisés par le BRP System](http://www.legrog.org/systemes/basic-role-playing)
</NOWIKI>

*Ce qui donnera :* **Thème / Jeu(x) :** [Les jeux motorisés par le BRP System](http://www.legrog.org/systemes/basic-role-playing)

***un éditeur en particulier :** faites pointer le(s) jeu(x) en question vers la base de données du GROG http://www.legrog.org

*Exemple pour Les Éditions Descartes :*
<NOWIKI>
[Les jeux de Descartes Éditeur](http://www.legrog.org/editeurs/descartes-editeur)
</NOWIKI>

*Ce qui donnera :* **Thème / Jeu(x) :** [Les jeux de Descartes Éditeur](http://www.legrog.org/editeurs/descartes-editeur)
