### Généralités
Le magazine Backstab est issu de la reprise par [Halloween Concept](http://www.legrog.org/editeurs/halloween-concept) du magazine [Plasma](../plasma/) des [Éditions Siroz](http://www.legrog.org/editeurs/asmodee-editions-siroz).

| --- | --- | --- |
| **Code ISSN :** 1276-9436 | **Langue :** français | **Thème / Jeu :** Actualité et matériel de jeu généraliste |
| **Description :** Actualité ludique, critiques, aides de jeu et scénarios pour des jeux variés |  |  |
| **Remarque :** Le titre *Backstab* signifie "coup de poignard dans le dos" et est une allusion à un type de coup disponible pour la classe de personnage "roublard" dans *Donjons & Dragons*. Le magazine était connu pour son ton acerbe et irrévérencieux. Le magazine Backstab a sa [Fiche Wikipédia](https://fr.wikipedia.org/wiki/Backstab). |  |  |
